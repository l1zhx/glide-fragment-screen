# Fixed-count clustering and sequential selection

## Cohort and chemical identity

The orchestrator audits all finite DockingScore poses in the supplied file and exports up to10000 sorted poses. This is not necessarily10000 distinct compounds and does not prove full-library coverage. Chemical clustering uses RDKit FragmentParent, Uncharger and canonical tautomer enumeration, canonical isomeric SMILES deduplication, then the lowest DockingScore state per parent. Original MAEGZ chemistry/coordinates are preserved for export. CSV input reuses parent_smiles and score, restandardizes and recomputes parent descriptors/LE; it does not export MAEGZ.

Morgan fingerprints use radius2 and2048 bits, without explicit chiral fingerprinting. Chemical-parent identity may preserve distinctions not represented by the fingerprints. Tautomer standardization can affect stereochemistry. The software versions and data order must be archived.

## Exactly100 groups

The input distance is1-Tanimoto. A SciPy condensed distance vector uses **upper-triangle row order**, not the lower-triangle order used by the former RDKit Butina implementation. Average-linkage hierarchical clustering uses mean pairwise distance between clusters. cut_tree with n_clusters=[100] cuts the hierarchy at the requested count, including in tied-distance cases. The code verifies exactly100 nonempty groups and rejects fewer than100 parents.

References: [SciPy linkage](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html), [cut_tree](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.cut_tree.html).

This is a coarse partition, not a fixed minimum-similarity clustering. Equal fingerprints can be split if the requested count forces it. IDs are assigned by decreasing size and deterministic input-order tie break. No biological quality is encoded in ID. A medoid is an actual member with the greatest sum of within-group Tanimoto similarity. Mean pairwise Tanimoto excludes self-pairs; singletons use the explicit convention1, which is not evidence of robust support.

For10000 parents the float64 condensed vector has49,995,000 entries (~381MiB). Average linkage and medoid evaluation require additional quadratic work/memory. The example16GB allocation is a starting budget, not a measured10k benchmark.

## Sequential gates

1. Sort standardized parent molecules by DockingScore ascending. Retain the best2000 by default, **including all exact ties at the boundary**.
2. Within that score pool, retain the best500 by descending LE=-DockingScore/HAC, again including boundary ties.
3. Optionally exclude explicitly requested review alerts; default is annotation only.
4. Count eligible members per cluster. Order eligible clusters by **global cluster_size descending**, where global means all parents included in this clustering run, not just those passing the gates.
5. Within each eligible cluster choose the lowest DockingScore candidate; ties use descending LE then original entry. Cluster-size ties use the representative score, LE and cluster ID. Default cap1 gives one candidate per cluster. An explicit cap2 performs one-per-cluster rounds before taking second members.

There is no weighted score, no percentile combination and no hidden preference for unflagged molecules. No stage can rescue a compound rejected by an earlier gate. The output reports actual gate thresholds, requested and returned counts and eligible cluster counts. Candidate shortages are not silently filled. The two outputs are generated by the same order, so Top30 is a prefix of Top60 when both exist with the same parameters. All eligible cluster representatives are also exported, including ones outside the requested shortlist.

2000/500 are tunable review budgets, not proven optimal thresholds. LE is mathematically coupled to score and favors small HAC. Cluster size is influenced by library composition and forced coarse grouping; using it at the final step is an explicit policy, not evidence of binding. Review cohort sizes and chemical coverage through sensitivity analysis.

The final cluster-size step is a review ordering rule, not an additional numeric cluster-size cutoff. Both global cluster_size and eligible_cluster_size are reported. This avoids silently adding an unrequested minimum-size threshold or treating a high ID as a bad cluster.

## Sensitivity

selection_sensitivity.py reuses a saved cluster_assignments.csv, applies a grid of score/LE gates and exports actual thresholds, eligibility, selected compound IDs and Jaccard overlap. This does not repeat clustering or choose an optimum automatically. Empty-set overlap is left blank; a stable list does not establish biological validity. Gate boundary comparisons use numerical values, not rounded plot labels. New CSVs write floating values with17 significant digits to support round-trip filtering.

## Other analysis

The density script uses best-score records per supplied parent-ID (title by default), whereas chemical clustering deduplicates standardized chemistry. These populations and their HAC definitions can differ. A reliable --id-property avoids merging unrelated compounds with the same title. --keep-all-poses changes the interpretation to pose occupancy.

Ligand centers are heavy-atom geometric centroids. Each record contributes1 to centroid density and total1 across its heavy atoms. Gaussian smoothing sigma2.5Å and grid spacing1Å are defaults. Bounds include receptor and ligand extents. Each map is independently normalized by its maximum, so values are not absolute probabilities or comparable magnitudes across runs. Alignment is not performed automatically; use the original docking coordinate frame.

DockingScore axes omit units. Neither score-derived LE nor pose occupancy estimates experimental affinity. Centering a grid on the protein centroid does not prove whole-protein coverage: recover actual box bounds and prepared construct. Pocket labels are manual residue anchors, not automatically established binding sites.

## Manual selection

New Top60 needs new pocket review and explicit --rows/--pockets. Historical archived30 selection is accessible only through --use-archived-selection on the original paired CSV/MAEGZ. Its hashes, original ranks and labels are preserved. The chemical figure shows name, DockingScore, LE, cluster and pocket; source ranks remain in data. No cross-docking step is required.

## Regional enrichment and dynamic follow-up

[REGIONAL_EF.md](REGIONAL_EF.md) defines winning-pose regional EF, explicit ambiguity/outside cases and the full-background denominator. It does not implement active/decoy validation or physicochemical correction. [SWIMMING_INTERFACE.md](SWIMMING_INTERFACE.md) documents existing-volume annotation, detection zeros, contact-state alignment and correlated-frame limitations.

review_cluster_pockets.py uses researcher-supplied labels and binds each sheet to a source CSV hash. Pocket-label fractions/entropy summarize reviewed members only; coverage and source cohort must accompany them. It neither predicts pockets from fingerprints nor tests inhibition.

Reference implementations: [RDKit fingerprints and similarity](https://www.rdkit.org/docs/GettingStartedInPython.html), [SciPy average-linkage hierarchy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html). This repository implements project-specific postprocessing rather than an official Schrödinger screening recommendation.
